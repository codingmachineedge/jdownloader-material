# JDownloader Material

JDownloader Material is an independently implemented JavaFX desktop app for direct HTTP(S) files. Its rewritten mint-teal Material 3 interface keeps queue controls, search, navigation, telemetry, and nonblocking status feedback in stable positions while network and disk work continue in the background.

- [Install or run the app](Getting-Started)
- [Learn the interface](Interface)
- [Explore the interactive GitHub Pages demo](https://codingmachineedge.github.io/jdownloader-material/)
- [Download the latest release](https://github.com/codingmachineedge/jdownloader-material/releases/latest)

Normal launches use the real `DirectHttpEngine`. The app accepts direct `http://` and `https://` file URLs; it is not a general JDownloader-core client and does not claim host-account, captcha, plugin, extraction, updater, or My.JDownloader support. The primary destinations are fixed views rather than user-created workspace tabs.
