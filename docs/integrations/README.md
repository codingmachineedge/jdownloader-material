# Desktop integrations

| Feature | Contract | Status |
| --- | --- | --- |
| External editor | [External editor](external-editor.md) | Implemented |
| Installed JDownloader | [Loopback bridge](installed-jdownloader-bridge.md) | Implemented |

Integrations are optional Windows desktop conveniences. They degrade safely and never become a
launch dependency. The installed-JDownloader bridge is a strict loopback client; it does not expose
an inbound API or connect to My.JDownloader cloud services.
