Transfers

Direct HTTP(S) queue

Behavior

LinkGrabber probes direct URLs, then the Downloads queue starts, pauses, resumes, reorders and retries transfers away from the JavaFX thread. Partial files use resumable .part state.

Configuration

Settings cover destination, collision policy, global and per-host concurrency, speed cap, retry policy and clipboard monitoring.

Failure modes

Timeouts, invalid redirects, range refusal, disk errors and size mismatch become actionable non-blocking notifications; resumability falls back safely when a host cannot continue.

Security

Only explicit HTTP(S) URLs are fetched. Paths are normalized, retained signed URLs are not shown in diagnostics, and background work never asks for cloud credentials.

Verification

DirectHttpEngineSmoke and DirectHistorySmoke cover transfer, retry, restart and history behavior.

Navigation

Persistent browser-style tabs

Behavior

Tabs reorder, pin, group, collapse, overflow and restore their full structure. Four independent searches cover the current strip, one group, group names and every tab.

Configuration

Use Settings › Navigation or a tab context menu. Pinned tabs stay in a protected leading region; groups keep names, colors, order and collapsed state.

Failure modes

Empty or invalid bulk-close queries never run. Pinned tabs remain excluded until explicitly included, and a preview identifies every affected visible label.

Security

Search evaluates only local visible labels under bounded inputs. Closing a tab never inspects hidden page content.

Verification

The site smoke checks roving focus, overflow, independent search state, persistence keys, pin/group controls and previewed inverse bulk close.

Related: Safe search · Appearance

Search

Plain-first bounded regex builders

Behavior

Every search owns an adjacent anchored builder with literals, classes, anchors, groups, alternation, quantifiers, raw pattern, flags, sample text, matches, captures, copy and export.

Configuration

Plain text is always the default. Regex is an explicit local choice; query, pattern, flags and validation remain synchronized only within the originating field.

Failure modes

Inputs are capped, zero-width matches advance safely, invalid expressions remain visible, and patterns with common nested-quantifier hazards are refused before evaluation.

Security

Patterns and samples never leave the browser or enter analytics. The site has no outbound search endpoint.

Verification

Static and browser checks cover valid, invalid, Unicode, multiline, zero-width, captures, no-match and adversarial cases.

Material 3

Per-element appearance system

Behavior

Right-click an element or press Shift+F10 to open its anchored non-modal editor. Global tokens and per-state overrides apply live, including to the editor itself.

Configuration

Font family, axes, size, weight, decoration, spacing, effects, direction and alignment sit beside continuous color controls and translated color-space values. Presets export and import as JSON.

Failure modes

Unsupported browser font axes remain visible with a capability explanation. Invalid colors are preserved in the entry field and never silently replace the saved value.

Security

Profiles stay in local storage unless the visitor explicitly downloads or imports a file. Imports are size-, schema- and value-checked.

Verification

The smoke contract asserts deep controls, self-theming targets, profile round-trip hooks, reset paths, contrast output and every required translated color space.

Language and voice

English, Hong Kong Cantonese and bilingual

Behavior

Language mode persists. Bilingual mode keeps English primary and adds compact Cantonese. Independent 1–5 funny levels style English and Cantonese copy without changing facts.

Configuration

The header and Settings share one language value. Two sliders are independent and resettable; the disclosure states that the tone also affects errors and warnings.

Failure modes

A missing translation falls back to English while preserving the action, affected item and recovery path. Long bilingual labels wrap instead of clipping.

Security

Tone never removes security facts or makes destructive effects ambiguous. Humor targets code absurdity, never the visitor or their data.

Verification

Browser checks switch all three modes, all five levels, narrow widths and persisted restart state.

Feedback

Corner notifications and reviewable history

Behavior

Information and success messages auto-dismiss in the bottom-right stack. Warnings and errors persist until dismissed. Every item remains in a bounded searchable history.

Configuration

Settings control quiet mode. Actions can retry, undo, open or show details without turning an informational event into a blocking modal.

Failure modes

When storage is unavailable the live stack still works and reports that history could not persist.

Security

History is local, bounded and sanitized; it never stores credentials, signed URLs or imported profile content.

Verification

Checks cover stacking, live announcements, timeout policy, dismiss targets, history bounds and independent safe search.

Startup delight

Exactly one-percent dim-sum surprise

Behavior

After first run, an eligible launch draws fresh cryptographic randomness once. A winning 1-in-100 draw shows one bilingual dish card without focus theft or startup delay.

Configuration

The surprise can be disabled persistently. Language and funny levels style its surrounding copy while the factual dish names and alt text stay unchanged.

Failure modes

It never appears on first run, during an error/update/mid-task marker, twice in one session, with reduced-motion animation, or after opt-out.

Security

Four catalogued photos are bundled below site/assets/dimsum; there is no request, tracker or third-party CDN.

Verification

The smoke checks catalog/image presence, eligibility gates, a single guarded random draw and the 1-of-100 comparison.

Behavior

The desktop viewer composes text search with typed or calendar date ranges and exports the exact filtered Markdown view.

Configuration

Data

Append-only local Git history

Behavior

Downloads, LinkGrabber, workspace structure and non-secret settings snapshot meaningful changes in an isolated application-data repository.

Configuration

History supports labels, retention, pruning and export. It never places a .git directory inside a visitor-owned download folder.

Failure modes

An unchanged state creates no revision. A history-write failure is reported but never blocks the operation the visitor requested.

Security

History stays local; encrypted records remain ciphertext and stable identifiers preserve authenticated-encryption bindings across restore.

Verification

JGit and direct-history smokes prove restore-as-new-revision, redo, no-op suppression and isolated paths.

Related: Transfers · Appearance

Integrations

External editors and installed JDownloader

Behavior

Windows editor launch uses structured process arguments. The optional JDownloader bridge exposes typed local Remote API operations without My.JDownloader cloud.

Configuration

Editor choice persists. Bridge URLs accept only strict loopback HTTP(S), with bounded requests, responses and timeouts.

Failure modes

Missing editors and stopped JDownloader instances become non-blocking actionable errors. Redirects are never followed and destructive requests require one-use confirmation.

Security

Credentials, fragments, traversal and non-loopback authorities are rejected. Diagnostic strings omit bodies and secret parameters.

Verification

Loopback-only server tests cover route encoding, cancellation, bounds, redirects, confirmation tokens and secret-safe diagnostics.

Related: Notifications · Transfers

Delivery

Test-gated Windows release

Behavior

Every branch push and manual dispatch runs desktop smoke checks before a Windows hosted runner builds one self-contained x64 EXE.

Configuration

Unique monotonic tags use workflow run and attempt numbers. A deterministic catalog entry supplies one bundled dim-sum photo and bilingual code name.

Failure modes

A failed check publishes no release. Later failure removes only the incomplete draft; unexpected assets, sizes or upload states refuse publication.

Security

Hosted runners are disposable, pull requests do not run the release path, tokens stay in GH_TOKEN, and tag events cannot create an automation loop.

Verification

A qualifying published release must be non-draft and contain exactly the EXE plus one decodable bundled image.
